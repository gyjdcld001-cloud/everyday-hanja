# 매일 한자 (Everyday Hanja)

평일(월~금) 아침 **5분**, 하루에 **한자 한 자**씩 **뜻(훈)과 음**을 익히는 웹 앱입니다.
글자 모양을 외우는 대신, 초등학교 교과서에 자주 나오는 **어휘 4개**와 **예문** 속에서 한자의 뜻과 소리를 익힙니다.

## 실행 방법

설치나 빌드 과정이 없는 정적 웹 앱입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

GitHub Pages에 그대로 올려도 동작합니다.

## 입장과 학생별 기록

- 처음 화면에서 **이름(아이디)** 을 쓰고 입장합니다. 이 기기에서 공부한 학생의 이름이 버튼으로 나와 누르면 이어서 학습합니다.
- 배운 한자, 퀴즈 결과, 글짓기, 급수 시험 기록이 **학생별로 따로 쌓입니다.** (브라우저 localStorage에 이름별로 저장)
- **학습 기록** 탭: 내 누적 통계(학습한 날, 배운 한자, 글짓기 수, 퀴즈 정답률)와 날짜별 활동, 그리고 이 기기에서 공부한 학생들을 한눈에 비교하는 표가 있습니다.
- 서버가 없으므로 기록은 그 기기(브라우저)에만 남습니다. 교실 공용 태블릿처럼 한 기기에서 여러 학생이 쓰는 경우에 알맞습니다.

## 하루 학습 흐름 (약 5분)

| 요일 | 내용 |
| --- | --- |
| 월~목 | ① **1일 후 복습**: 지난 학습일의 한자(퀴즈 2문제) + 틀렸던 한자 최대 2자<br>② **오늘의 한자**: 음훈 익히기 → **활용 어휘 뜻 연결하기**: 어휘 속 한자마다 아래에 작은 글씨로 음훈이 나오고, 이를 힌트로 어휘 4개의 뜻을 직접 골라 연결한 뒤 예문을 봅니다<br>③ **짧은 글짓기**: 배운 낱말을 하나 이상 넣어 한 문장 쓰기(저장됨)<br>④ **확인 퀴즈**: 어휘를 보고 오늘 한자의 음훈 쓰기, 오늘의 한자를 활용한 어휘가 **아닌** 것 고르기(소리는 같고 한자가 다른 어휘가 함정으로 나옴) → 다 푼 뒤 **정답·틀린 까닭·풀이** |
| 금 | 위 과정 + ⑤ **일주일 복습**: 이번 주 한자 5자 퀴즈와 정리표 |
| 토·일 | 쉬는 날. 금요일에 일주일 복습을 놓쳤다면 주말에 할 수 있고, 자유 복습(5문제)도 할 수 있어요 |

- **에빙하우스 망각 곡선**에 맞춰 잊어버리기 직전에 다시 떠올리도록 **1일 후 → 금요일(주간) → 급수 시험**으로 복습합니다.
- 퀴즈나 시험에서 틀린 한자는 '다시 볼 한자'에 모여 다음 복습에 다시 나옵니다.
- 하루를 빠뜨려도 진도는 밀리지 않고 다음 학습일에 이어서 배웁니다.

## 급수 시험

한 급수의 한자를 모두 배우면 **급수 시험** 코너가 열립니다.

1. **전체 복습**: 급수의 한자 전체를 훑어봅니다. '뜻·음 가리기'를 켜면 스스로 떠올려 볼 수 있습니다.
2. **시험**: 어휘(예: 學校)를 보여 주고, 색으로 표시된 한자의 **뜻과 음을 직접 씁니다**. 20문항 또는 전체 문항 중에 고를 수 있고, 70점 이상이면 합격입니다.
   - 음은 두음 법칙(력→역, 녀→여 등)을 인정합니다.
   - 뜻은 기본형(배울 → 배우다, 곧을 → 곧다)도 인정하며, 다르게 표현한 정답은 '인정하기' 버튼으로 맞게 처리할 수 있습니다.

## 수록 한자

한국어문회 한자능력검정시험 배정 한자 기준입니다.

| 급수 | 새로 배우는 한자 | 상태 |
| --- | --- | --- |
| 8급 | 50자 | ✅ 수록 |
| 7급Ⅱ | 50자 | ✅ 수록 |
| 7급 | 50자 | ✅ 수록 |
| 6급Ⅱ | 75자 | ✅ 수록 |
| 6급 | 75자 | ✅ 수록 |
| 5급Ⅱ ~ 1급 | — | 준비 중 |

지금은 모두 300자로, 평일에 한 자씩 배우면 약 60주 분량입니다. 한자마다 어휘 4개와 예문 1개가 들어 있습니다.

### 한자 추가하기

`js/data.js`의 `GRADES` 배열에 같은 형식으로 급수를 이어 붙이면 앱 전체(학습, 목록, 시험)에 자동으로 반영됩니다.
어휘에 학습 한자가 아닌 글자가 들어가면 `js/hunum.js`에 그 글자의 음훈을 추가해 주세요.

```js
['學', '배울', '학', '學校,학교,공부하는 곳;學生,학생,배우는 사람;數學,수학,수와 셈을 배우는 과목;入學,입학,학교에 들어감', '동생이 초등학교에 입학(入學)했어요.'],
```

## 파일 구성

```
index.html      앱 화면 틀
css/style.css   디자인 (라이트/다크 모드)
js/data.js      한자 데이터 (학습 한자 300자)
js/hunum.js     활용 어휘에 나오는 그 밖의 한자 271자의 음훈
js/app.js       입장, 학습 일정, 활동, 퀴즈, 급수 시험, 학생별 저장
```

테스트할 때는 주소 뒤에 `?date=2026-10-02`처럼 날짜를 붙이면 그 날짜(예: 금요일)의 화면을 미리 볼 수 있습니다.
